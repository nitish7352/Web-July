# Minor Project Implementation

## Project
Weather App + Movie Search App

## Requirements Covered
- Search weather by city
- Current temperature and weather condition
- Humidity and wind speed
- Weather API error handling
- Responsive interface
- Movie search using a public movie database API
- Movie posters and details
- Ratings and release information
- Invalid/no-result handling
- Arrow functions
- Template literals
- Destructuring
- ES modules
- DOM manipulation
- Event handling and form processing
- Promises / async-await
- Fetch API
- JSON handling
- API response/error management
