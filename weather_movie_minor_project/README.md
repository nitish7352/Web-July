# Weather App + Movie Search App

This project implements the two applications required in the Minor Project:
1. Weather App
2. Movie Search App

Technology: HTML5, CSS3, JavaScript ES6+, REST APIs, Fetch API.

## APIs
- Weather: OpenWeatherMap Current Weather API
- Movies: OMDb API

## Setup
1. Open `weather-app/index.html` and `movie-search-app/index.html` through a local server (recommended).
2. Put your API keys in the corresponding `js/config.js` files.
3. For OpenWeatherMap, create an API key at https://openweathermap.org/
4. For OMDb, create an API key at https://www.omdbapi.com/apikey.aspx
5. Do not publish API keys in a public GitHub repository. For a student/demo project, keep them local or use a backend/proxy.

## Features
### Weather App
- Search by city
- Temperature and weather condition
- Humidity and wind speed
- API/error handling
- Responsive UI

### Movie Search App
- Search movies
- Posters and movie details
- Ratings and release year
- Invalid/no-result handling
- Responsive UI

The JavaScript demonstrates arrow functions, template literals, destructuring, ES modules, DOM manipulation, events, promises, async/await, Fetch API, JSON handling and error handling.
